# DEC-013: base de plugin propio

Fecha: 2026-11-12T05:13:09-05:00.
Feature: F-005, dependencias F-001/F-004 validadas.
Evidencia: pruebas de loader/esquema/ACL y HTTP descritas en evidencia F-005.

Decisión: versionar únicamente plugins/RvSoftware mediante excepción limitada de
gitignore. Plugin interno 0.1.0, base exacta documentada, ruta query nativa y ruta
friendly solo cuando rewrite está activado. Hook CSS sin modificar CSP ni núcleo.
Migración baseline 1 sin DDL: plugin_schema_versions nativo evita inventar tablas
de infraestructura o reglas de negocio antes de sus features.

Impacto: ninguna dependencia, SPA, base adicional o servicio productivo. Scripts
de prueba copian solo el plugin propio a un directorio aislado habilitado; el
servidor nativo sin plugin conserva un directorio separado deshabilitado.
Rango de compatibilidad declarado no equivale a pruebas de futuras versiones.

Siguiente acción: integrar diseño y flujos nativos en F-006. Recuperación:
deshabilitar carpeta en copia revisada, sin eliminar datos ni deshacer migraciones.
MySQL sigue pendiente como motor de ejecución; baseline no tiene DDL de negocio.
