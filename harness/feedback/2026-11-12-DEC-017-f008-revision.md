# DEC-017 · Revisión y privacidad de horas

Fecha: 2026-11-12T22:36:10-05:00. Feature: F-008.

Evidencia: pruebas unitarias y HTTP/API de
[F-008](../evidence/2026-11-12-f008-revision.md), contrato DEC-008.

Decisión: extender los servicios nativos por DI para limitar las proyecciones de
horas a las propias del miembro. Líderes de cada proyecto y administradores ven
el conjunto. Las sesiones pendientes admiten clasificación y aprobación; las
aprobadas solo rectificación autorizada, con versiones y auditoría. Las tareas
con sesiones aprobadas no se trasladan a otro proyecto para conservar su origen.
La API privilegiada nativa conserva su alcance administrativo; las operaciones
comerciales nuevas requieren identidad de usuario. Enlaces públicos no exponen
horas de otros usuarios. No se toca el núcleo.

Impacto: los históricos opacos solo son visibles para líder/administrador; no se
atribuyen horas sin autor. PicoDB subquery requiere literales de IDs enteros
derivados exclusivamente del servidor, siguiendo el patrón nativo; el resto de
consultas usa parámetros. No hay facturas, tarifas ni consumos hasta F-010.

Siguiente acción: F-009 clientes/bolsas; conservar pruebas de regresión. SQLite
ejecutado; migración MySQL pendiente de ensayo en instancia aislada.
