# Contrato de cambio (plantilla, sin estado de ejecución)

- Feature autorizada / decisión / fuente y fecha:
- Objetivo y comportamiento observable:
- Entradas UI/API/CLI y objetos/roles afectados:
- Alcance incluido / excluido y archivos permitidos:
- Especialidades y modalidad consulta/delegación:
- Solución mínima / alternativas / compatibilidad y consumidores:
- Riesgos, datos sintéticos y destino aislado:
- Criterios fijados antes del cambio:
- Pruebas normal/error/borde/permisos pertinentes y regresión:
- Rendimiento: línea base/condiciones/umbral si aplica:
- Recuperación de código y datos si aplica:
- Resultado por criterio, comandos, exit codes, observado y limitaciones:
- Evidencia / decisión / siguiente acción:

Rellenar en la decisión/evidencia pertinente, no crear un segundo backlog aquí.
No equiparar un contrato planeado con pruebas ejecutadas.
